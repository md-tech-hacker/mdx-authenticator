# Autofill — MDX Authenticator

MDX Authenticator plans to support Android Autofill Service.

## Features

- Fill saved credentials in Android apps
- Fill credentials in Chrome/websites
- Save password prompt
- Update password prompt
- Account picker for multiple saved accounts
- Biometric/App Password before filling

## Android setup

Users must enable MDX Authenticator as their Autofill provider from Android settings.

Accessibility helper and overlay permissions should be optional fallback features only.
