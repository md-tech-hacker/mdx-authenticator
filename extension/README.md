# MDX Authenticator Browser Extension

The MDX Authenticator browser extension is planned for future release.

## Planned Features

- Detect login forms
- Autofill usernames/passwords
- Save password prompt
- Generate strong passwords
- Connect to MDX Authenticator web dashboard
- Sync encrypted vault data
- Require secure unlock/mobile approval
- Decrypt locally only

## Release

Extension builds will be published in:

```txt
releases/extension/
```
